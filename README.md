# Primer Landing Page

Marketing site for [Primer](https://github.com/ravmax-rdl/Primer), an open-source, local-first academic vault where Pi probes, teaches, assesses, and records evidence in Obsidian.

Built with Vite, React, TypeScript, Motion, Geist, and Geist Mono.

## Run

```bash
bun install
bun run dev
```

## Validate

```bash
bun run build
bun run lint
```
